# taskline v2.3.0

## ✨ 새 기능
- **반복 작업 지원** — 일/주/월 단위 반복 작업 생성 가능.
- **CSV 내보내기** — 작업 목록을 CSV로 내보내 외부 도구(스프레드시트 등)에서 활용 가능.

## 🐛 버그 수정
- 자정을 넘긴 마감 시각이 타임존 처리 오류로 잘못 표시되던 문제 수정.
- 제목이 빈 작업 저장 시 발생하던 충돌 수정.

## ⚡ 성능
- 작업 목록 렌더링 속도 약 2배 개선 — 대규모 목록에서 체감 향상.

## ⚠️ 주의 (Breaking)
