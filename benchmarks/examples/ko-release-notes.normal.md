# taskline v2.3.0

이번 릴리스는 두 가지 새 기능과 함께 안정성·성능을 개선했습니다. **Node 16 환경을 사용 중이라면 업그레이드 전 아래 "주의 사항"을 먼저 확인하세요.**

## ✨ 새로워진 것 (할 수 있는 일이 늘었어요)

- **반복 작업 지원** — 매일·매주처럼 주기적으로 생기는 작업을 한 번만 등록하면 자동으로 반복 생성됩니다. 같은 작업을 매번 다시 만들 필요가 없습니다.
- **CSV 내보내기** — 작업 목록을 CSV로 내보내 스프레드시트·외부 도구에서 분석하거나 백업할 수 있습니다.

## 🛠 더 안정적으로 (이전엔 잘못 동작하던 것)

- **자정을 넘긴 마감 시간이 올바르게 표시됩니다** — 타임존에 따라 마감일이 하루 어긋나 보이던 문제를 수정했습니다.
- **제목이 빈 작업으로 인한 비정상 종료 해결** — 제목 없이 작업을 추가해도 앱이 충돌하지 않습니다.

## ⚡ 더 빨라진 것

- **목록 렌더링 속도 약 2배 개선** — 작업이 많은 목록도 더 빠르고 부드럽게 표시됩니다.

## ⚠️ 주의 사항 (확인이 필요해요)

- **Node 16 지원이 종료되었습니다** — 이 버전부터는 Node 16에서 동작을 보장하지 않습니다. 최신 LTS(Node 18 이상)로 업그레이드한 뒤 사용하세요.
