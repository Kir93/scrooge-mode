# Scrooge persistence corpus — KO boundary artifacts
#
# Probes for both `## Boundaries` classes: commit messages and PR descriptions
# (permanently excluded — written normally, no compression), and outbound drafts
# (Slack, DM, announcements, mail), which fall under Docs·prose — compressed for
# padding but keeping tone and 존댓말. Either way the artifact stays in normal
# prose while a compressed register is active, so a 음슴체 ending inside it IS
# the violation.
#
# Every prompt ends by asking for `=== OUTPUT ===` before the artifact, so
# persistence-score.py can tell the artifact from talk about the artifact — the
# first false positive it hit. One prompt per non-comment line; \n is expanded.
