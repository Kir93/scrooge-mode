# Scrooge doc-generation benchmark corpus — KO (held-out; document / prose artifacts).
#
# Each non-comment line is ONE self-contained document-GENERATION task — the surface
# the doc-compression `## Boundaries` rule targets, distinct from prompts/ko.txt
# (conversational Q&A). Information is PINNED in every prompt so `normal` and
# `scrooge:ko/full` must convey the same facts; the only variable is register /
# verbosity. Disjoint from the tuning corpus — never tune rules against this set.
# `\n` expands to a newline (run.py load_prompts). Mirror of en-docgen.txt.

README의 "설치" 섹션을 작성해줘. 패키지 `taskline`(npm). 요구: Node 18+, 설치 `npm i taskline`, 초기화 `npx taskline init`(`taskline.config.json` 생성), 환경변수 `TASKLINE_TOKEN` 필수(없으면 기동 실패). 설치 명령 코드 블록과 최소 동작 예시 포함.
기능 명세 문서를 작성해줘. 기능: 다크 모드 토글. 요구사항 4개 — (1) 헤더 우상단 토글 버튼, (2) 선택은 `localStorage` `theme` 키에 영속, (3) 최초 방문은 OS `prefers-color-scheme` 따름, (4) 전환은 200ms 트랜지션. 비목표: 테마별 커스텀 색상 편집기. 수용 기준 포함.
이 REST 엔드포인트의 API 레퍼런스를 작성해줘. `POST /api/v1/orders`. 바디: `items`(배열, 필수), `coupon`(문자열, 선택), `idempotency_key`(문자열, 필수). 응답: 201 생성된 주문, 400 검증 실패, 409 중복 key, 402 결제 실패. 인증: `Authorization: Bearer <token>`. 요청·응답 예시 포함.
마이그레이션 가이드를 작성해줘. `charts` 라이브러리 v2 → v3. 호환성 깨짐 4개 — (1) `<Chart data>` prop이 `series`로 개명, (2) `colors` 배열 → `theme` 객체, (3) `onClick(idx)` → `onClick(event, point)`, (4) CommonJS 빌드 제거(ESM 전용). 각 항목 before/after 코드와 마이그레이션 순서 포함.
아키텍처 개요 문서를 작성해줘. 시스템: URL 단축 서비스. 컴포넌트 5개 — API 게이트웨이, 단축 서비스(base62 인코딩), Redis 캐시, PostgreSQL(원본 URL 저장), 분석 워커(클릭 비동기 집계). 요청 흐름(생성·리다이렉트)과 각 컴포넌트 역할 포함.
릴리스 노트를 작성해줘. `taskline` v2.3.0. 변경 6개 — feat: 반복 작업 지원, feat: CSV 내보내기, fix: 자정 넘긴 마감 타임존 버그, fix: 빈 제목 작업 충돌, perf: 목록 렌더 2배 개선, chore: Node 16 지원 종료. 각 항목을 사용자 영향 기준으로 그룹핑.
트러블슈팅 가이드를 작성해줘. CLI 도구 `taskline`. 흔한 오류 3개 — (1) `TASKLINE_TOKEN not set`(원인: 환경변수 누락, 해결: export 후 재실행), (2) `config not found`(원인: init 미실행, 해결: `npx taskline init`), (3) `409 sync conflict`(원인: 다른 기기 동시 편집, 해결: `taskline pull --rebase`). 각 오류의 증상·원인·해결 포함.
신규 개발자 온보딩 문서를 작성해줘. 로컬 환경 5단계 — (1) repo 클론, (2) `pnpm install`, (3) `.env.example` → `.env` 복사 후 `DATABASE_URL` 설정, (4) `pnpm db:migrate`, (5) `pnpm dev`(localhost:3000). 각 단계 명령과 확인 방법 포함.
설정 레퍼런스 문서를 작성해줘. `taskline.config.json` 옵션 6개 — `token`(문자열, 필수), `syncInterval`(숫자, 기본 300, 초), `theme`(`light`|`dark`, 기본 `light`), `notify`(불리언, 기본 true), `maxItems`(숫자, 기본 1000), `endpoint`(문자열, 기본 공식 API). 각 옵션의 타입·기본값·용도 표 포함.
ADR(아키텍처 결정 기록)을 작성해줘. 결정: 세션 저장소로 Redis 채택(대안: in-memory, DB 세션). 맥락: 다중 인스턴스 수평 확장 필요. 결정 근거: 공유 상태·TTL 만료·낮은 지연. 결과: Redis 운영 의존성 추가, 장애 시 세션 유실(수용). 상태 accepted.
컴포넌트 사용 문서를 작성해줘. `<Button>` (React). props 4개 — `variant`(`primary`|`secondary`|`ghost`, 기본 `primary`), `size`(`sm`|`md`|`lg`, 기본 `md`), `disabled`(불리언), `onClick`(함수). 사용 예시 3개(기본, 비활성, ghost+sm) 포함.
배포 런북을 작성해줘. 프로덕션 배포 절차 5단계 — (1) `main`에서 `npm run build`, (2) 스테이징 스모크 테스트, (3) `npm run deploy:prod`, (4) 헬스체크 `/healthz` 200 확인, (5) 5분 에러율 모니터. 롤백: `npm run deploy:rollback`(직전 릴리스로 복귀). 각 단계 명령과 실패 시 조치 포함.
